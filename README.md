#progetto_counter

## Descrizione

Il seguente progetto riguarda la progettazione di un contatore dotato di due pulsanti + e -. Cliccando su uno dei due è possibile aggiungere o sottrarre un'unità al valore che viene mostrato dal contatore.
Impostazione attraverso html, lo stile definito con css e infine reso interattivo grazie a javascript.

## Prova l'applicazione

👉 https://michelemoltrasio.github.io/progetto_counter/

## Funzionalità principali

- Addizione 
- Sottrazione
- Conteggio

## Tecnologie utilizzate

Html, Css e JavaScript
